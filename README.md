# examples

Code examples for building on Initia across different VMs, SDKs, and frontend frameworks.

## Contents

| Directory | Description |
|-----------|-------------|
| [`evm/`](./evm/) | MiniEVM guides: custom ERC20, ERC20Factory, address conversion, Slinky oracle |
| [`movevm/`](./movevm/) | MoveVM smart contract example |
| [`wasmvm/`](./wasmvm/) | WasmVM contract examples |
| [`initiajs/`](./initiajs/) | initia.js SDK usage examples |
| [`frontend/`](./frontend/) | Frontend integration with InterwovenKit (React, EVM, RainbowKit) |
| [`minitia/`](./minitia/) | Minitia rollup configuration examples |

## Getting Started

Each subdirectory has its own README with setup instructions. Start with the VM or SDK relevant to your use case.
